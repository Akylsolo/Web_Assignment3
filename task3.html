Navbar Component Demonstration

Responsive Navigation Component

The brand logo is anchored to the left, navigation items align strictly to the right, and the entire structure collapses into a mobile hamburger menu on viewports smaller than 992px.

Interactive Demo Next: Portfolio Page →

1. Left-Aligned Brand

Configured via standard navbar-brand class. Features custom SVG glyph and prominent branding visible across all screen sizes.

2. Right-Aligned Links

The unordered list utilizes Bootstrap utility class ms-auto (margin-start: auto), pulling all navigation links and call-to-action buttons to the far right.

3. Responsive Collapse

The navbar-expand-lg breakpoint keeps desktop navigation expanded on wide screens and automatically folds into an animated hamburger toggler below 992px.
